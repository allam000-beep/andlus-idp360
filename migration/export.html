🔄 أداة ترحيل بيانات الأندلس

تُصدّر هذه الأداة كل بيانات النظام المخزّنة في هذا المتصفح إلى ملف واحد، لاستيراده في قاعدة البيانات الجديدة.

  1. افتح هذه الصفحة من نفس المتصفح الذي يحوي بيانات النظام.
  2. اضغط زر التصدير أدناه.
  3. سيُنزّل ملف andlus_export.json.
  4. سلّمه لمسؤول التقنية لاستيراده عبر npm run migrate.
