# المرحلة 4: ربط الواجهة بالخادم

## ما أُنجز
رُبطت الواجهة (React) بالخادم عبر طبقة API وسيطة، دون إعادة كتابة الواجهة — واختُبر التكامل فعلياً.

## الاستراتيجية: طبقة `api.js` تحاكي `st`
بدل إعادة كتابة عشرات مواضع التخزين، بُنيت طبقة `public/api.js` تحاكي واجهة `st` القديمة (`get`/`set`/`getShared`/`setShared`) لكن تنادي الخادم. فالتحويل تمّ بأقل تعديل ممكن.

## الملفات الجديدة
| الملف | الوظيفة |
|-------|---------|
| `public/api.js` | طبقة الـ API: مصادقة + ترجمة مفاتيح st لنداءات الخادم |
| `public/index.html` | صفحة الواجهة (React من CDN + الـ bundle) |
| `public/app.bundle.js` | الواجهة المبنية (تُولَّد آلياً) |
| `scripts/transform_frontend.js` | يحوّل الـ artifact JSX لواجهة سيرفر |
| `scripts/build_ui.sh` | يبني الـ bundle كاملاً |

## ما يفعله التحويل آلياً
1. يستبدل تعريف `st` ليستخدم `andlusAPI` بدل `window.storage`.
2. يستبدل كل نداءات `window.storage` المباشرة (صفر بقايا).
3. يزيل `import React` (يُوفَّر عالمياً من CDN).
4. يربط شاشة الدخول بالمصادقة الحقيقية (`andlusAPI.auth.login`) بدل مقارنة كلمات المرور في الكود.
5. يحوّل `export default` إلى `window.__AndlusApp`.

## معالجة أمنية إضافية
- شاشة الدخول لم تعد تقارن كلمات المرور محلياً — تصادق عبر الخادم (bcrypt + JWT).
- إخفاء هوية مُقيّمي الزملاء صار على الخادم — لا يمكن تجاوزه بتعديل المتصفح.

## الاختبار الفعلي
- ✅ كل الأصول تُحمّل (index.html / api.js / app.bundle.js = 200)
- ✅ الـ bundle سليم صياغياً ويشير لـ React العالمي صحيحاً
- ✅ تكامل الطبقة: `get(users)` يُعيد camelCase، `getShared(weights)` يعمل
- ✅ إنشاء/قراءة البيانات عبر الطبقة يعمل

## إعادة البناء عند تحديث الواجهة
```bash
npm run build:ui           # يحوّل ويبني app.bundle.js
```
